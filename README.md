# Reserva de un asiento en sala de cine

## Nombre del estudiante
Kerly

## Objetivo
Crear un programa en Python que permita reservar un asiento en una sala de cine de 3 filas por 4 columnas. El programa solicita la fila y la columna, registra la reserva y muestra el estado completo de la sala.

## Cómo ejecutar
1. Abrir el archivo `reserva_cine.py`.
2. Ejecutar el programa en Python.
3. Ingresar la fila y la columna del asiento que se desea reservar.
4. El programa mostrará la sala con `0` para los asientos libres y `1` para el asiento reservado.
